# 上班啟示錄：午休鬥牛 2v2（demo）

《上班啟示錄》的番外：午休時間，大家跑到頂樓球場打半場 2v2 鬥牛。挑兩個同事組隊，電腦控制你的隊友和對手。每個人都有自己的大招。

免費、不用登入，沒有儲值、等待時間或社群功能。手機直式、電腦都能玩。

![比賽](design/v0.1_比賽_電腦.jpg)

## 怎麼玩

- **比賽**：2 分鐘，或先到 21 分的隊伍贏。三分線外進球算 3 分，線內 2 分。時間到平手就打延長賽，下一球得分的贏。
- **換球權**：進球後由對手從三分線外弧頂發球。搶到防守籃板或抄截之後，要**先把球帶出三分線**才能投籃（三分線會發黃光提示）。
- **操作**：你操作持球的人。隊友接到球後，控制權會跟著換過去。防守時，傳球鍵改成「換人」。

| | 電腦 | 手機 |
|---|---|---|
| 移動 | WASD／方向鍵 | 左半邊按住拖（搖桿出現在按的地方） |
| 投籃（持球）／蓋帽（防守） | J 或空白鍵 | 🏀 大橘鍵 |
| 傳球（持球）／換人（防守） | K | 👐 綠鍵 |
| 抄截 | L | ✋ 藍鍵 |
| 大招 | I 或 E | 頭像圓鍵（集滿會轉彩虹） |
| 暫停 | P／Esc | 右上 ⏸ |

- 籃下按投籃會上籃，有時候會灌籃。對手擋在面前、距離越遠，越不容易進。
- 防守時貼近持球的人再抄截。對手起跳投籃時，你也起跳，就有機會蓋火鍋。
- **大招集氣**：時間會慢慢累積，傳球、得分、助攻、抄截、蓋帽、籃板也會加。記分板頭像下的細條是四個人的集氣。

## 素材

- 角色模型直接沿用《上班啟示錄》`office-apocalypse/models/`（已壓縮、已綁骨架的走路／小跑步動作）。沒有新做 3D 動作：運球、投籃、舉手蓋帽、歡呼、灌籃都是用程式轉手臂骨頭、加跳躍和壓扁做出來的。
- 頭像是載入時用 3D 模型直接拍的大頭照（`makePortraits`），七個人風格一致，不另外畫圖。
- 音效和配樂全部用 WebAudio 合成（`js/fx.js`、`js/music.js`），沒有音檔。

## 開發

- 純 HTML＋Three.js r170（`vendor/`，本機放好，不連 CDN），不用建置。
- 本機預覽：`python3 tools/serve.py 4460 .`（不快取，改完重新整理就是新版）。也可以在上一層用 launch.json 的 `office-basketball`。
- `js/main.js` 開頭的 `CFG` 是手感數值（比賽時間、目標分數、跑速、命中、抄截、大招集氣），`CHARS` 是七個角色的能力和大招說明。
- `js/court.js`：球場、籃架、白板籃板、落地窗；`js/world.js`：渲染、畫質（自動／漂亮／流暢）、鏡頭；`js/assets.js`：角色模型載入（跟主遊戲同一份）。
- 開不起來的說明卡、手機自動降畫質、擋放大和選取，都跟《打卡衝衝衝》同一套。
- 測試用：`?play` 直接開打；`?auto` 讓你這隊也交給電腦；主控台的 `G`（`G.start('kui','jie')`、`G.special('jie')`、`G.step(1/60, 600)`、`G.LOG`）。
